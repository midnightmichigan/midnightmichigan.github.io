A note from the maker

Hearthside Printables is a one-person shop in Michigan. I built these tools one at a time, each after catching myself about to paste something private (an API response with real customer data, a family bank statement) into a free web tool I knew nothing about. Investigations have found most top free formatters and converters ship your paste off the device within about a second. So the rule for everything here is simple: no backend at all. The absence of a server is the feature.

Honest status: the store is up and the tools are finished and tested, and sales so far are zero. Distribution is the part I am worst at, which is partly why this page exists. No testimonials on this page, because there are no customers to quote yet. What I can show you instead is the work: every bundle ships its full test suite, so you do not have to take my word for any of it.

If you paste other people’s data into free web tools for work, try this once: open your browser’s developer tools, watch the Network tab while you paste, and then decide. That experiment is how this whole catalog started.
